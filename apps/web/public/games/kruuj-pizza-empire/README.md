# KRUUJ Pizza Empire

## Ficha Técnica Oficial (KRUUJ-PROC-001)
- **ID do Jogo:** KJ-kruuj-pizza-empire
- **Versão:** 1.0.0
- **Categoria:** Tycoon / Gestão / Casual
- **Orientação Recomendada:** Ambos (Responsivo com suporte a Portrait e Landscape)
- **Plataformas Homologadas:** Web Desktop (Chromium, Firefox, Safari) e Web Mobile (Android Chrome, iOS Safari)

## Controles
- **Desktop:** Teclado (Setas / WASD) e Tecla E / Barra de Espaço para interagir.
- **Mobile:** Joystick virtual na tela e botão touch 'E' para interagir.

## Integração Plataforma
- Compatível com **KRUUJ SDK v1.0** (retrocompatível com PokiSDK).
- Ciclo de vida: `gameLoadingFinished`, `gameplayStart`, `gameplayStop`.
